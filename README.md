# Тренажёр Виктории Барановой

Android-приложение для тренировки таблицы умножения.

## Возможности

- **Учу таблицу** — таблица для любого числа от 2 до 9, кнопка «Проверить себя».
- **Тренировка** — выбор нескольких чисел и количества примеров (10 / 20 / 30).
- **Быстрый тест** — 20 случайных примеров на всю таблицу.
- Цифровая клавиатура, подсветка верных и неверных ответов, прогресс-бар.
- Итог со звёздами, разбор ошибок, лучший результат для каждого режима, счётчик решённых примеров.

Работает без интернета, данные хранятся на телефоне.

## Как собрать APK

### Вариант 1. Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. `File → Open` и выберите папку `BaranovaTrainer`. Дождитесь синхронизации Gradle (понадобится интернет).
3. Подключите телефон с включённой отладкой по USB и нажмите ▶ **Run**,
   либо `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2. Без установки Android Studio (GitHub)

1. Загрузите папку проекта в новый репозиторий на GitHub.
2. Откройте вкладку **Actions → Build APK → Run workflow**.
3. Когда сборка завершится, скачайте `app-debug` из раздела **Artifacts**.

## Технологии

Kotlin, Jetpack Compose (Material 3), minSdk 26 (Android 8.0), targetSdk 34.
Пакет: `com.baranova.multiplication`.
